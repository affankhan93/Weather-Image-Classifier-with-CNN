# Weather-Image-Classifier-with-CNN
(This is a Major Project)

A Convolutional Neural Network (CNN) built with PyTorch that classifies weather conditions from a single photo, with an interactive Streamlit web app for real-time predictions. 

## Overview 
This project trains custom CNN to recognize 11 different weather conditions from images, then serves the trained model through a clean, interactive Streamlit interface where users can upload a photo and instantly see the predicted weather type along with confidence scores for every class. 

### Usage
1. Open the app in your browser
2. Upload a weather photo(.jpg, jpeg, or .png)
3. View the predicted weather class, confidence score, and a breakdown of probabilities across all 11 classes.
